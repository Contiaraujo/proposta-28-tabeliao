Este site realiza atendimento do cartório?

Não. Este é um protótipo independente para apresentação. As páginas mostram uma proposta de organização; os percursos digitais são fictícios.

Como saber quais documentos levar?

Use a página do serviço para entender o assunto e confirme as informações e documentos necessários nos canais oficiais. Esta proposta não define exigências documentais.

Posso consultar preços aqui?

A página de emolumentos encaminha à fonte oficial verificada. O protótipo não reproduz valores nem calcula custos.
